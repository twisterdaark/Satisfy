# الرجوع لنسخة قديمة (Rollback)

Owner: Claude-A · SAT-ONLINE-091 (plan U385) · بالعربي للمالك. الأوامر وأسماء الزراير زي ما هي.

**إمتى:** لما نسخة اتدمجت تبوظ اللعبة للاعيبة (شاشة سودا، أو مش بتحمّل، أو حاجة أساسية واقفة)، والتصليح هياخد وقت.

## 1. رجّع الموقع (GitHub Pages بيتبني من main)

1. افتح الـ PR اللي بوّظ في GitHub، ودوس **Revert** تحت. GitHub بيعمل PR جديد بيلغي التغيير.
2. ادمج الـ PR ده. الموقع بيتحدث لوحده في دقيقة أو اتنين.
3. قول للاعيبة يعملوا Ctrl+F5. على الموبايل يقفلوا التاب ويفتحوه تاني.
4. لو مش عارف أنهي PR اللي بوّظ: رجّع آخر واحد، وجرّب.

**علامة النجاح:** رقم النسخة في شاشة البداية (ALPHA v…) بيرجع للرقم اللي قبله.

## 2. رجّع قواعد الداتابيز (لو المشكلة جت بعد ما نشرت قواعد)

في PowerShell جوه فولدر المشروع:
```powershell
git fetch origin
git checkout --detach origin/main
npx.cmd -y firebase-tools@latest deploy --only database --project satisfy-online-8yjeix
git checkout main
```
- قواعد main شغالة مع كل النسخ اللي على main، وكل حاجة اتدمجت ليها قواعدها هناك.
- لو عايز قواعد يوم معين: بدل `origin/main` حط رقم الـ commit بتاع اليوم ده (من صفحة Commits في GitHub).

## 3. سيفات اللاعيبة

الاختبار `tests/regression/rollback.test.cjs` بيتأكد من كل ده في كل PR:
- **سيف اتكتب بالنسخة الجديدة بيشتغل في النسخة القديمة.** الدهب واللفل والحاجات بتفضل زي ما هي.
- **النسخة القديمة لما تحفظه مبتشيلش منه حاجة.** حتى الحاجات اللي هي متعرفهاش بتفضل فيه. ولما الموقع يرجع للنسخة الجديدة، السيف بيرجع زي ما كان بالظبط.
- **لو اللعبة لقت سيف من نسخة أحدث منها،** بتحفظ نسخة احتياطية منه زي ما هو (`satisfy_proto_v4.backup.newer-v…`) قبل ما تلمسه.
- **نسخة الكلاود** هي نفس السيف، فبتمشي بنفس الطريقة.

## 4. صورة من الداتابيز قبل أي حاجة خطيرة

الباك أب الأوتوماتيك محتاج خطة Blaze (U347). لحد ده، قبل أي نشر قواعد كبير:
1. افتح Firebase Console، وبعدها Realtime Database.
2. دوس ⋮، وبعدها **Export JSON**، واحفظ الملف عندك.
3. لو احتجته: ⋮، وبعدها **Import JSON** من نفس المكان.

**خلي بالك:** الـ Import بيمسح كل اللي في الداتابيز وبيحط الملف مكانه. استخدمه بس لو الداتا نفسها باظت.

## 5. القتال عبر WebSocket (لو اتشغّل)

القتال عبر السيرفر الصغير (`backend/ws-relay.cjs`) مقفول افتراضيًا. لو اتشغّل وعمل مشكلة: شيل `combat=…` من الرابط، أو امسح عنوانه من `src/net/firebase-config.js`. القتال بيرجع للداتابيز زي الأول. السيرفر ده مبيخزنش أي داتا، فمفيش حاجة تترجع. التفاصيل في [COMBAT_RELAY.md](COMBAT_RELAY.md).
