# دليل اختبار الأونلاين للمالك (Twister)

Owner: Claude-A · محدّث لحد SAT-ONLINE-064 (2026-10-20) · الخطوات بالعربي، وأسماء الزراير زي ما هي في اللعبة.

## 0. انشر قواعد الداتابيز قبل ما يتدمج أي PR فيه "rules: deploy first"

افتح فولدر المشروع في PowerShell، وبعدين:
```powershell
git fetch origin
git checkout --detach origin/claude-a/rules-next
npx.cmd -y firebase-tools@latest deploy --only database --project satisfy-online-8yjeix
git checkout main
```
- `claude-a/rules-next` دايمًا فيه قواعد main، ومعاها إضافات كل الـ PRs المفتوحة اللي محتاجة قواعد. يعني نشر واحد بيغطيهم كلهم، وأي نسخة على main بتفضل شغالة معاه.
- **علامة النجاح:** يطلعلك `rules syntax ... is valid`، وبعدها `Deploy complete!`.
- **لو طلع `Syntax error`:** متعملش حاجة، وابعت الصورة. القواعد القديمة بتفضل شغالة.
- **لو طلع `not a git repository`:** إنت مش جوه فولدر المشروع. اعمل `cd` للفولدر الأول.

## 1. افتح اللعبة

- **الرابط:** `https://twisterdaark.github.io/Satisfy/`. بيفتح أونلاين لوحده، ولو عايز تلعب أوفلاين ضيف `?net=off`.
- **حسابين:** استخدم حسابين Google مختلفين على جهازين، أو على متصفحين، واعمل Ctrl+F5 على الاتنين بعد كل تحديث.
- **أول دخول:** "Play online"، وبعدها اختار حساب Google، وبعدها ID مميز (مرة واحدة بس).
- **علامة الأونلاين:** فوق، بيظهر "Online · players: 2".

## 4. لو حاجة مش مظبوطة

ابعت صورة للشاشتين ومعاها اكتب:
- إمتى حصلت؛
- وإنتوا فين في الخريطة؛
- وكام لاعب كنتوا؛
- وهل حد عمل ريفريش.

لو ظهر صندوق "نسخة جديدة": اعمل ريفريش للصفحة اللي ظهر فيها بس. الصفحة الأقدم بس هي اللي بتطلبه.
